# FE-Ticket-Tracking-System-Sheetal-Karan-Ayush

### Prerequisites
- Node.js
- yarn

### Installing

To set up the project on your local environment, follow these steps:

1. **Clone the Repository**
    First, you need to clone the repository. And checkout to dev branch.

2. **nvm (Node Version Manager)**
    - **Install Node Version**: You can install it by running:
        'nvm install'

    - **Yarn Installation**: You can install it by running:
        'npm install -g yarn
'
3. **Install the necessary dependencies using yarn**: Run this commend
        'yarn'

4. **Run the Development Server**: Run this commend
        'yarn dev'

    The app will be available at http://localhost:<PORT>, PORT specified in your .env file .

5. **To format the Code**

    ```bash
    yarn prettier
    ```

6. **To lint the Code**: `yarn lint'

7. **To Fix Lint errors**: 'yarn lint:fix'
